Element card guide

Every card packs the same five pieces of information. This one is boron.

Atomic number Element name

  • Atomic number bottom left

    The atomic number is 5. It is the number of protons in the atom, and it decides which element the atom is.

    atomic number = number of protons = 5

  • Mass number top left

    The mass number is 11. It counts the protons and neutrons together. Electrons are too light to count.

    Mass number = protons + neutrons
    Neutrons = mass number − atomic number
    Neutrons = 11 − 5 = 6

  • Charge top right

    The charge is 0, so this boron atom is neutral. Charge compares protons to electrons. A positive charge means the atom has fewer electrons than protons. A negative charge means it has more.

    Electrons = atomic number − charge
    Electrons = 5 − 0 = 5

    If the charge were 3+, the atom would have 5 − 3 = 2 electrons. If it were 1−, it would have 5 − (−1) = 6 electrons.

  • Element symbol center

    B is the symbol for boron. A symbol is one or two letters. The first is a capital and the second, if there is one, is lowercase, like Na or Cl.

  • Element name bottom right

    Boron is the name of the element. The name, the symbol and the atomic number always go together.
